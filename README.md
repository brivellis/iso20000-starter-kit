# ISO/IEC 20000-1 SMS Starter Kit — Brivellis

Free starting set of 17 files (v1.2): templates and worked examples for an ISO/IEC 20000-1:2018 (incl. Amd 1:2024) service management system.

Download, details and licence: https://brivellis.com/resources/iso-20000-starter-kit/

Free for internal use within one organisation. No redistribution or resale. Templates, not audit or legal advice.
